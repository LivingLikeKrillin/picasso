# `picasso` — 미들웨어의 가운데

**이 모듈이 곧 이 저장소가 만드는 것이다.** 나머지는 그 부품이다(ADR 38). 이름이 저장소와 같은 이유가 그것이다.

층 ③(배정과 결정)이 여기 산다 — 상류의 일감 하나를 원자 단위 열로 나누고, 계약(④)으로 내려보내고, 하류가 말한
것과 **설비가 말한 것**을 결합해 상류에 결과를 통보한다.

---

## 무엇이 여기 있나

| 파일 | 무엇 |
|---|---|
| `Model.kt` | **정준 모델.** 실행 상태 두 축 · 근거 등급 E0~E3 · `ExecutionUnit` · `JobOrder`/`JobResponse` · `CancelReport` |
| `LogicalCapability.kt` | 논리적 능력의 인터페이스와 셋(`PrepareSequencedRack` · `DeliverContainer` · `InspectAsset`) + 능력 단위 설정(시간창 δ · `IN_DOUBT` 유예 · 정체 유예) |
| `Middleware.kt` | 엔진. 접수 → 조합 → 실행 → 근거 결합 → 통보. `pump()` 가 한 걸음 민다 |
| `Ports.kt` | 하류로 나가는 문 — `RobotPort`(계약 소비자) · `CellSignals`(설비, E2) · `AmrFleetPort`(플릿, E1) |

---

## 경계 — 무엇을 알고 무엇을 모르나

**기종을 모른다.** 게이트 7번이 이 모듈의 소스에 벤더·모델 문자열이 들어오면 실패시킨다. 벤더 코드를 정준 분류로
옮기는 일은 **어댑터의 것**이고(ADR 33), 그 위의 실행 구조에 `if robot == …` 가 생기면 정준 모델이 아니다.

**능력도 거의 모른다.** 엔진에 능력별 분기가 없다 — `InspectAsset` 을 더할 때 엔진이 얻은 것은 **일반 규칙 셋**
(등급 상한 거절 · 결과 참조 · 취소 거절 노출)이었고 `if 능력 == …` 는 하나도 안 생겼다(§15.93). 그 성질이 깨지면
능력군 추가가 다시 엔진 수술이 된다.

**배차·라우팅·자원 중재는 밖이다.** 조합과 실행 상태는 안이다 — 둘은 떼어낼 수 없다.

---

## 이 층에만 있는 것

- **`UNVERIFIED`.** *로봇은 끝났다는데 설비가 말이 없다.* 계약은 기체 하나만 아니까 이 대조를 할 수 없다.
- **`upstream_ack`.** 통보가 갔는가는 **물리와 독립**이다. 명령 재시도와 통보 재시도를 가르는 축이다.
- **근거 등급 결합.** E0(로봇 보고) · E1(플릿 확인) · E2(설비 신호) · E3(사람). 요구 등급을 못 채우면 접수 자체를
  거절한다 — 받아 놓고 `UNVERIFIED` 로 끝내는 것은 상류에 *될지도 모른다* 고 말한 셈이다.
- **지연 이벤트 보존.** 옛 버전의 종착은 실패가 아니라 보존되고, 새 버전의 기대에 대고 다시 본다(15.1).

## 어느 시험이 무엇을 증명하나

| 시험 | 무엇 |
|---|---|
| `SequencingRackTest` | 시나리오 ② — 슬롯 넷, 버전 갱신, 취소, 설비 결합 |
| `DeliverContainerTest` | 시나리오 ① — 플릿 위임(E1), 인계 신호 |
| `InspectAssetTest` | 시나리오 ③ — **능력군 추가에 엔진 변경 없음** |
| `EvidenceWindowTest` | 시간창 δ · 재확인 · `UNVERIFIED` · `VERIFICATION_MISMATCH` |
| `InDoubtTest` · `LateEventTest` | 접수 여부 불명의 해소 순서 · 버전 갱신 중 지연 이벤트 |
| `EventStreamTest` | 스냅샷 권위 + 재생 + 축출 뒤 재세움 |
| `ProgressStallTest` | 정체 가시화 — **못 재는 기체는 판정하지 않는다**(계약 0.8.0) |

## 정직하게 적어 둘 것

★**상류도 설비도 플릿도 실물이 아니다.** 상류는 시험이 소비자 역할을 하고, 설비(`CellMimic`)와 플릿
(`AmrFleetMimic`)은 **계약을 우리가 지은 대역**이다. 이 층의 시험이 초록인 것은 *우리 가정 안에서 일관되다* 는
뜻이고, 구간별 등급은 [`docs/verification.md`](../docs/verification.md) 10·11 번 줄에 있다.
