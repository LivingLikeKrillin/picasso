# profile-model — 기종 프로파일 파싱 모델 (Profile Document Model)

기종 능력 프로파일 JSON 문서를 역직렬화하여 불변 도메인 모델인 `ProfileDocument` 객체로 제공하는 경량 모델 라이브러리입니다. 스키마 검증이나 계약 투영 로직을 포함하지 않고 순수한 데이터 구조체 바인딩만을 담당합니다.

---

## 1. 모듈 분리 배경 (ADR 29)

`gate` 정적 검증 모듈과 `mimic` 런타임 에뮬레이터가 완전히 동일한 프로파일 문서를 파싱해야 하지만, 두 컴포넌트는 아키텍처 원칙상 상호 의존성을 가질 수 없습니다 (§3.2). 파싱 모델을 한쪽에 귀속시키지 않고 독립 모듈로 추출함으로써 데이터 모델의 중복 정의와 드리프트를 방지합니다.

---

## 2. 아키텍처 경계 및 검증 책임 분리

본 모듈은 유효성 검증을 수행하지 않습니다. JSON 스키마 검증은 `profile/schema/`를 기반으로 게이트 검사 3번이 집행하며, 본 모듈은 문법적으로 유효한 JSON을 단순 객체화합니다. 4대 구조적 정합성 규칙(발행 간격 역전, 중복 키 등)은 검증하지 않으므로, 게이트 검증을 거치지 않은 비정상 프로파일로도 에뮬레이터가 기동될 수 있는 한계(§15.19)가 존재합니다.
