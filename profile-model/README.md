# `profile-model` — 프로파일 문서의 읽기 전용 모델

능력 프로파일 JSON 을 읽어 `ProfileDocument` 로 만든다. **그뿐이다** — 검증도 투영도 여기 없다.

## 왜 따로 있나 (ADR 29)

`gate` 와 `mimic` 이 **같은 문서를 읽어야 하는데** 서로를 몰라야 한다(§3.2). 한쪽에 두면 다른 쪽이 그것을
두 번째로 옮겨 적게 되고, 두 벌로 쓰는 순간 이 프로젝트가 막으려는 드리프트를 우리가 낸다.

## 경계

**스키마 검증은 여기가 아니다.** JSON Schema 는 `profile/schema/` 가 정본이고 검사는 게이트 3번이 한다.
이 모듈은 *읽을 수 있는 문서* 를 객체로 만들 뿐이며, 구조 규칙 넷(발행 간격 뒤집힘 · 중복 키 …)도 안 본다 —
그래서 `mimic` 이 게이트가 거절할 프로파일로 기동할 수 있다(§15.19).
