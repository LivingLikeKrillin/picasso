# 완료 조건 — 이 저장소는 무엇이 되면 끝인가

2026-09-10. 초판을 리뷰가 **반증 불가능하다**고 판정해 §4 를 새로 세우고 도장을 해시로 바꿨다.

## 왜 이 문서가 있나

**이 저장소는 완료 조건 없이 지어졌다.** 그 자리를 `docs/limits.md` 가 대신 메웠고, 무엇을 더 지을지가
*열린 항목이 몇 개 남았나* 로 정해졌다. 그런데 그 문서는 **구조상 안 빈다** — 갈래 셋 중 둘(의도적 밖,
밖에서만 닫힘)은 지어서 못 없애고, 나머지 하나도 새 기능이 새 한계를 낳는다. **안 비는 문서를 소진
목록으로 쓰면 끝이 없다.**

끝은 *남은 항목의 수* 가 아니라 **주장과 증거의 관계**로 정의한다. 그 축은 이미 있다 — 게이트,
`docs/verification.md` 의 등급, `DocumentClaimsTest`, `docs/contract.md` 의 담보 표. 이 문서는 새 규율을
들이지 않고 **있던 축에 끝을 표시한다.**

## 완료 조건

> **이 저장소가 밖을 향해 하는 모든 주장이 셋 중 하나다 — 받쳐졌거나, 열린 것으로 적혔거나, 지워졌거나.
> 셋 중 어느 것도 아닌 문장이 0 이고, §4 의 대가를 치렀으면 이 저장소는 끝이다.**

## 1. 주장이란 무엇인가

**"지금 이 저장소가 이렇다" 고 밖을 향해 말하는 문장.**

| | 무엇 |
|---|---|
| **주장이다** | 현재 상태의 단정 · 능력과 보장의 선언 · 수와 경계와 범위의 진술 |
| **주장이 아니다** | *왜 그렇게 정했나* 의 논거 — 그것은 결정이고 ADR 이 진다 |
| **주장이 아니다** | *그때 무슨 일이 있었나* 의 기록 — 날짜가 박혀 있고 그때 참이었던 것을 적는다 |
| **주장이 아니다** | `docs/limits.md` 의 **표 세 개** — 그것은 열림의 목록 자체다. 자기를 근거로 자기를 받치는 고리를 끊는다 |

★**주장을 세지 않는다.** 초판은 도장에 *받침 N · 열림 M* 을 적게 했는데, 리뷰가 **두 사람이 같은 수를
못 낸다**고 짚었다(모듈 나무 25 줄은 1 인가 25 인가). **재현 안 되는 수는 대조에 못 쓴다.** 그래서 셈을
버리고, 도장은 **해시와 열림 id** 만 나른다 — 둘 다 기계가 다시 만들어 댈 수 있다.

## 2. 주장의 자리

**손으로 적지 않는다. 글롭으로 정한다.**

| 규칙 | |
|---|---|
| 든다 | `README.md` |
| 든다 | `docs/**/*.md` |
| 든다 | `<모듈>/README.md` (빌드가 아는 모듈에서) |
| 든다 | `tools/vendor-manifest/README.md` |
| **뺀다** | `docs/superpowers/plans/**` — 계획은 날짜가 박힌 기록이다 |
| **뺀다** | 설계 문서의 **§15 이후** — 일지다 |

`docs/limits.md` 가 이미 *"§15 는 대장이 아니라 일지다"* 라고 적었다. 이 선은 그 문장 위에 세운 것이다.

★**설계 문서의 경계는 절 경계이지 파일 경계가 아니다.** 파일 시스템은 §14 와 §15 사이를 모른다. 그래서
**`## 15.` 으로 시작하는 제목 줄을 경계로 삼는다** — 기계가 찾을 수 있고, 그 줄이 사라지면 시험이 먼저
빨개진다. 도장은 그 줄 **바로 앞**에 둔다(파일 끝이 아니다 — 파일 끝은 조건 밖 구역이다).

★**`tools/vendor-manifest/` 는 빌드의 모듈이 아니라 글롭에 안 걸린다.** 그런데 `README.md` 가 그것을
직접 링크한다 — 밖을 향한 문서다. 손으로 한 줄 더한다. **그 줄은 `gate/build.gradle.kts` 의 `repoInputs`
에도 필요하다**(안 그러면 `Repo` 의 문지기가 던진다). 그 파일이 여섯 번 물린 구멍의 일곱 번째다.

## 3. 판정 셋

1. **받침** — `docs/contract.md` 담보 표와 **같은 인용 형식**으로 시험을 댄다: `` `모듈` · `XxxTest` ·
   `시험 이름` ``. 형식을 통일하면 *시험이 나중에 지워지는 경우*의 대조가 이미 있는 시험으로 따라온다.
   런타임 구간을 지나는 주장이면 `docs/verification.md` 의 **등급**을 함께 댄다 — **초록은 구간마다 뜻이
   다르다.** ★**문서 대조·게이트처럼 어느 구간에도 안 걸리는 시험은 등급을 안 댄다**(`verification.md`
   의 13 구간은 런타임 경계이지 문서 대조가 아니다).
2. **열림** — `docs/limits.md` 의 **id 를 대야 한다**(`§15.34` · `C-3`). 대지 못하면 열림이 아니다.
3. **없음** — **지운다.** 근거가 없으면 단정을 지우고 비워 둔다. 없는 근거를 지어내지 않는다.

## 4. 열림의 대가 — 이 조건이 실패할 수 있게 만드는 것

초판의 치명상은 이것이었다: **열림에 아무 대가가 없어서** 받쳐진 주장을 전부 `limits.md` 로 내려 적으면
조건을 만족한다. 그러면 *밖을 향해 아무것도 보증하지 않는 저장소* 가 **완료**로 선언된다. 대가 셋을 붙인다.

1. ★**열림은 세어서 `limits.md` 에 적는다.** *"밖을 향한 문서가 드는 열림은 N 개다"* 를 적고,
   `CompletionCriterionTest` 가 도장에서 세어 댄다. **강등하면 N 이 늘고, N 을 늘리는 것은 문서를 고치는
   행위라 diff 에 보인다.** 이 저장소가 이미 하는 *"세어서 적은 것을 다시 센다"* 와 같은 장치다.
2. ★**`README.md` 는 "안에서 닫는다" 열림을 못 든다.** README 의 도장이 드는 id 는 `limits.md` 의
   §1(의도적 밖) 또는 §3(밖에서만 닫힌다)에만 있을 수 있다. **지어서 닫을 수 있는데 안 지은 것이
   저장소의 얼굴에 앉아 있는 채로 완료가 선언되는 것** — 그것이 이 조건의 유일한 치명상이다.
3. **강등은 사건이다.** 받쳐졌던 주장이 열림으로 내려가면 §15 일지에 적는다. 기계가 강제하지 않는다
   (일지는 조건 밖이다) — 1 번의 N 이 그 일이 일어났음을 드러내는 것까지가 기계의 몫이다.

## 5. 도장 — 날짜가 아니라 해시에 건다

문서 하나를 훑어 단정문을 셋으로 가르고, **도장 한 줄**을 남긴다.

```
> 마지막 대조: 2026-09-10 · sha256:1a2b3c4d5e6f · 열림: §15.34, C-3
```

해시는 **도장 줄을 뺀 본문**의 것이다. 그래서 **아무도 안 고치면 절대 안 빨개지고, 고치면 반드시
빨개진다.**

★**해시가 요구하는 것은 재감사가 아니다.** *"내가 이 문서를 고쳤고, 주장이 바뀌었는지 봤다"* 는 **도장
갱신**이다. 오타 하나에도 빨개지는 것이 대가이고, 그 대가를 치르는 이유는 하나다 — **날짜를 견주는
시험은 아무도 아무것도 안 고쳐도 어느 날 스스로 빨개지고, 그렇게 빨개지는 시험은 곧 꺼진다.** 해시는
빨개지는 순간이 **사람이 실제로 무언가를 고친 순간**과 일치한다.

## 6. 무엇이 기계로 지켜지고 무엇이 안 지켜지나

| | 무엇 |
|---|---|
| **기계가 지킨다** | 주장의 자리 **전부가 도장을 갖는가**(목록은 글롭에서) · **해시가 맞는가** · 열림 id 가 `limits.md` 에 **실재하는가** · 열림 총수가 `limits.md` 가 적은 N 과 **같은가** · README 가 §2 열림을 안 드는가 · 이미 있는 수·링크·담보 표 대조 |
| **사람이 지킨다** | 문장이 **참인가** · 강등을 일지에 적는가 |

## 7. 이 조건이 못 하는 것

- **주장이 맞는지는 안 본다.** 받쳐졌는지만 본다. **틀린 주장에 틀린 시험을 붙이면 통과한다** —
  그것을 막는 것은 결함 주입이지 이 조건이 아니다.
- **문장 단위의 판정은 사람의 것이다.** 기계가 대조하는 것은 도장·해시·id·총수뿐이다.
- **§4 는 강등을 막지 않는다. 값을 매길 뿐이다.** 마음먹으면 N 을 늘리고 강등할 수 있다. 이 조건이
  하는 일은 **그것을 조용히 못 하게** 하는 것이다.
- **C-3(실물 미검증)은 이 조건으로 안 닫힌다.** 열린 것으로 적힌 채 끝난다. 그것이 결함이 아니라
  **이 조건이 하려는 일**이다 — 지어서 못 닫는 것을 적어 두고 끝내는 것.

## 8. 끝난 뒤

끝났다고 적는다. 그 뒤의 변경은 *저장소를 끝내는 일* 이 아니라 **주장을 하나 더하고 그것을 받치는 일**
이다. 새 주장은 새 도장을 요구하고, 도장이 없거나 해시가 어긋나면 `CompletionCriterionTest` 가 잡는다.
**받침을 잃는 쪽**도 같은 문으로 잡힌다 — 시험을 지우면 담보 표의 대조가 먼저 빨개진다.
