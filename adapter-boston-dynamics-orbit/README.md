# adapter-boston-dynamics-orbit — Boston Dynamics Orbit 플릿 어댑터

Boston Dynamics Orbit 플릿 관제 시스템과 연동하는 전용 어댑터 모듈입니다. 개별 로봇 기체가 아닌 상위 플릿 매니저에 직접 연결되는 유일한 어댑터로서, 런타임 기체 자동 발견(ADR 37) 경로를 실증합니다.

---

## 1. 인터페이스 계약 적합성 및 도메인 분석

- 계약 적합성 정본: [`profile/distance/orbit.json`](../profile/distance/orbit.json)
- 벤더 API 전수 조사: [`profile/vendors/orbit.json`](../profile/vendors/orbit.json) · [`docs/vendors/orbit.md`](../docs/vendors/orbit.md)

**스킬 제약 특성**: 4대 표준 스킬 중 `navigate_to` 단일 스킬만을 지원합니다. 인터페이스 계약의 `location` 파라미터를 **사전 저작된 Orbit 미션 명칭**으로 해석하여 실행을 위임합니다 (ADR 35 확장). 조작 프리미티브나 저수준 속도 제어 명령은 지원하지 않습니다.

---

## 2. 어댑터 고유 아키텍처 기능

- **동적 기체 자동 발견 (Discovery Pipeline)**: `GET /robots` 호출을 통해 플릿이 관제하는 기체 목록을 조회하고, 적재 엔드포인트를 통해 레지스트리에 기체 및 어댑터 인스턴스를 자동 등록합니다.
- **실제 HTTP 네트워크 클라이언트 구현**: 남쪽 포트가 실제 네트워크 와이어를 통과하는 어댑터입니다 (CSRF 토큰 헤더 전파, Bearer 인증, 복수 응답 엔벨로프 처리). 공식 게시 스펙과 실제 벤더 파이썬 클라이언트 간의 4개 불일치 사항은 런타임 클라이언트 거동을 우선 준수하도록 구현되었습니다.
- **배치 런처 시퀀스 (§10.2)**: 플릿 접속 → 기체 발견 → 기체별 어댑터 바인딩 → 포트 개방 → `ONLINE` 상태 전이 파이프라인.
- **진행률 산출**: 벤더의 `Run.actionCount` 및 `pendingActionCount` 수치를 기반으로 정량 진행률을 계산합니다.

---

## 3. 미지원 기능 및 기술적 한계

- **취소·일시정지·갱신 미지원**: 진행 중인 미션을 강제 중단하거나 일시정지하는 API가 부재하여, 갱신 요청 시 `UPDATE_UNSUPPORTED` 거절 코드를 반환합니다.
- **스냅샷 관측 불가 (`UNAVAILABLE`)**: 플릿 관제 API가 개별 기체의 저수준 하드웨어 결함을 중계하지 않으므로 결함 스냅샷을 제공할 수 없으며, 상태는 `UNAVAILABLE`로 응답합니다.
- **기체 메타데이터 결손 (§15.106)**: 기체 자원 응답에 하드웨어 일련번호와 상세 기종 정보가 누락되어 있어, 현재는 발견된 기체에 단일 프로파일을 일괄 적용합니다.

---

## 4. 검증 환경 및 한계

실제 HTTP 프로토콜을 통과하지만 테스트 대상 서버는 자체 구축된 모의 스텁 서버입니다. 실물 Orbit 인스턴스와의 라이브 연동 검증은 미결(C-3)로 관리됩니다.
