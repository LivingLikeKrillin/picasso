# adapter-core — 로봇 어댑터 표준 도메인 어휘 (Adapter Domain Vocabulary)

물리 로봇 기체와 인터페이스 계약 간의 데이터 매핑을 정의하는 북쪽 표준 어휘 라이브러리입니다. `RobotAdapter` 인터페이스와 4개 기종별 어댑터 및 `adapter-host` 간에 교환되는 핵심 타입 모델을 정의합니다.

---

## 1. 아키텍처 설계 원칙: 판단 배제 및 보수적 기본값

- **어댑터의 판단 배제 원칙**: 어댑터는 물리 기체의 센서 및 제어기 상태를 인터페이스 계약의 표준 어휘로 충실히 **변환(Translation)**하는 역할만 수행하며, 비즈니스 수준의 정책 결정이나 재시도 판단은 계약 소비자(미들웨어)에 위임합니다.
- **보수적 기본값 (Fail-Closed Default)**: 재개, 재시도, 상세 결과 참조, 정량 진행률 측정 등은 벤더 API에서 미지원하는 경우가 빈번하므로 기본 구현을 '미지원/거절'로 정의합니다. '지원됨'을 기본값으로 두면 미지원 기체가 지원되는 것처럼 가장하는 오류가 발생하기 때문입니다.

---

## 2. 표준 도메인 어휘 체계

| 어휘 타입 | 모델링 상태 및 분기 기준 |
|---|---|
| `Acceptance` · `Applied` · `Refusal` | 작업 접수 성공 / 실행 거절 및 거절 상세 사유 (호스트가 표준 RejectionReason으로 매핑) |
| `HoldObservation` | 파지 상태 3분기: 파지 중(`HELD`), 미파지(`EMPTY`), **관측 불가(`NOT_OBSERVABLE`)** |
| `FaultObservation` | 결함 감지 2분기: 결함 확인(`DETECTED`), **관측 불가(`NOT_OBSERVABLE`)** |
| `ProgressObservation` | 진행률 2분기: 정량 측정 가능(`MEASURED`, 측정 기준 포함), **측정 불가(`UNMEASURABLE`)** |
| `SiteNames` | 공간 명칭 질의 3분기: 조회 성공, 기종 미지원(`UNSUPPORTED`), **일시적 질의 실패** |
| `FailureClasses` | 벤더 고유 에러 코드 → 15종 정준 실패 분류 매핑 (원본 코드는 `vendor_detail`에 보존) |
| `VendorSurface` | 하위 포트가 인용하는 벤더 공식 API 심볼 명시 어노테이션 (`vendor-manifest.txt`와 대조) |

'부재(None)'와 '불가지(Unknown)'를 동일 상태로 통합하지 않고 3분기/4분기 모델로 명확히 분리함으로써, 관측 불가능성을 하드웨어 정상 또는 부재로 오판하는 왜곡을 원천 방지합니다.

---

## 3. 기종 비인지 모듈 경계 (ADR 33)

특정 하드웨어 센서나 벤더 고유의 실패 원인을 열거형으로 정의하지 않으며, 관측 불가 사유는 문자열 기반으로 캡슐화합니다. 특정 기종에 특화된 타입 구조를 노출할 경우 게이트 검사 7번(기종 분기 금지)을 위반하게 되기 때문입니다.
