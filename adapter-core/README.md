# `adapter-core` — 어댑터의 북쪽 어휘

`RobotAdapter` 인터페이스와 그것이 주고받는 낱말. 어댑터 넷이 구현하고 `adapter-host` 가 부른다.

## 이 모듈의 규칙 하나

★**판단이 없다.** 어댑터는 로봇이 말한 것을 계약의 낱말로 **옮길** 뿐이고, 무엇을 할지는 계약 소비자가 정한다.

그리고 **기본값이 *없다* 다.** 재개·재시도·결과 참조·진행률은 벤더에 그 프리미티브가 없는 것이 흔해서
기본 구현이 거절이다 — *된다* 가 기본값이면 안 드는 기종이 조용히 되는 척한다.

## 어휘

| 타입 | 가르는 것 |
|---|---|
| `Acceptance` · `Applied` · `Refusal` | 받았다 / 못 받는다, 그리고 **왜** — 계약의 거절 코드로 옮기는 것은 호스트다 |
| `HoldObservation` | 들었다 / 빈손 / **못 본다** — 셋이다 |
| `FaultObservation` | 봤다 / **못 본다** |
| `ProgressObservation` | 잰다(무엇을 셌는지 포함) / **못 잰다** |
| `SiteNames` | 안다 / 못 한다 / **못 물어봤다** |
| `FailureClasses` | 벤더 코드 → 정준 분류. 원문은 `vendor_detail` 에 동반한다 |
| `VendorSurface` | 남쪽 포트가 벤더의 **무엇을 짚는지** 표시 — 매니페스트와 대조된다 |

**셋·넷으로 가른 것이 전부 같은 이유다** — *없다* 와 *모른다* 를 접으면 발신자가 거짓말을 하게 된다.

## 경계

**기종을 모른다.** *왜 못 보는가* 의 종류를 열거하지 않는다 — G1 의 압력 센서도 Spot 의 읽기 실패도
`NotObservable` 의 문자열 하나다. 종류를 열거하면 이 모듈이 기종을 알게 되고 게이트 7번이 막는다(ADR 33).
