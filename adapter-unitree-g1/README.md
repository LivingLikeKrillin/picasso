# `adapter-unitree-g1` — Unitree G1

기종을 아는 자리(ADR 33). 남쪽은 DDS(Cyclone) 다.

## 이 기종이 계약에 얼마나 닿나

정본은 [`profile/distance/unitree-g1.json`](../profile/distance/unitree-g1.json) ·
[`profile/vendors/unitree-g1.json`](../profile/vendors/unitree-g1.json).

요점만: **계약이 올라탈 층이 없는 쪽 끝이다.** 미션도 세계 모델도 없고 `SetVelocity` 같은 지시값이 전부라
드는 스킬이 `move_relative` 하나다. 반대쪽 끝(Spot 의 미션 층)과 함께 **계약이 명령 계층 위에 있다**는 판정의
근거가 된다.

★조사 범위가 한 번 잘못 잡혔다 — 서비스 넷 중 하나만 보고 재고 있었다(44 → 161 심볼). **범위를 먼저 적고
판정한다**(§15.75·§15.82)가 거기서 나왔다.

## 이 어댑터가 가진 것

- **취소를 우리가 만들었다** — 벤더에 취소 프리미티브가 없고 `SetVelocity(0,0,0)` 이 가진 전부다.
  프로파일의 `cancel_support: YES` 는 **로봇의 선언이 아니라 어댑터가 만든 것**이고 출처 문서가 그렇게 적는다.
- **갱신은 지시값 하나다** — 멈췄다 다시 시킬 필요가 없다. 갈아서 멈출 수 있으면 갈아서 다르게도 간다.
- **FSM 을 듣는다** — 명령은 받아들였는데 로봇이 `damp`·`sit` 에 있어 시간만 지나면 성공하는 구멍을
  `X_UNITREE_FSM_UNEXPECTED` 로 보이게 한다. 막지는 않는다.

## 못 하는 것

- **사이트 이름을 물어볼 데가 없다**(`Unsupported`). 세계 모델이 없다.
- **파지도 진행률도 못 본다** — 있는 것은 원시 압력값과 배터리 퍼센트다. 문턱을 우리가 정하면 그것은
  **로봇의 답처럼 보이는 우리의 짐작**이다.

## 남쪽에 전송이 없다

`G1Link` 는 인터페이스다. 인용만 매니페스트와 대조된다. 실물 확인은 열려 있다(C-3).
