# adapter-unitree-g1 — Unitree G1 어댑터

Unitree G1 휴머노이드 로봇 전용 하드웨어 어댑터 모듈입니다 (ADR 33). 남쪽 통신 계층은 Cyclone DDS 프로토콜을 추상화합니다.

---

## 1. 인터페이스 계약 적합성 및 도메인 분석

- 계약 적합성 정본: [`profile/distance/unitree-g1.json`](../profile/distance/unitree-g1.json)
- 벤더 API 전수 조사: [`profile/vendors/unitree-g1.json`](../profile/vendors/unitree-g1.json)

**저수준 제어 계층 특성**: 4개 기종 중 고수준 미션 엔진이나 객체 월드 모델이 부재한 최하위 명령 제어 계층에 해당합니다. `SetVelocity` 등 저수준 모빌리티 지시값만을 수신하므로 지원 가능한 표준 스킬은 `move_relative` 단일 항목입니다. 이는 Spot의 고수준 미션 계층과 대척점에 위치하며, 인터페이스 계약 계층이 명령 계층 상위에 위치해야 함을 입증하는 근거입니다.

초기 조사 시 4대 서비스 중 단일 서비스만 조사하여 44개 심볼로 축약 보고되었으나, 서비스 4종 및 IDL 전수 조사를 통해 161개 심볼로 확장 재측정되었습니다 (§15.75, §15.82).

---

## 2. 어댑터 주요 구현 기능

- **소프트웨어적 취소 로직 합성**: 벤더 API에 명시적 취소 프리미티브가 없으므로 `SetVelocity(0, 0, 0)` 속도 영점 명령을 조합하여 정지 동작을 합성합니다. 프로파일 상의 `cancel_support: YES`는 로봇 자체의 기능이 아닌 어댑터가 합성한 책임입니다.
- **연속 목표치 갱신**: 모빌리티 명령의 경우 물리적 재기동 없이 새로운 목표 속도 벡터를 연속 주입함으로써 즉시 갱신을 수행합니다.
- **기체 내부 FSM 모니터링**: 명령은 수신되었으나 기체 FSM이 댐핑(`damp`) 또는 착석(`sit`) 상태에 머물러 실행이 무효화되는 현상을 감지하고 `X_UNITREE_FSM_UNEXPECTED` 결함 코드로 상류에 노출합니다.

---

## 3. 미지원 기능 및 기술적 한계

- **공간 명칭 조회 미지원 (`Unsupported`)**: 기체 내부에 저작형 지도나 세계 모델이 부재하여 사이트 명칭을 질의할 수 없습니다.
- **파지 상태 및 진행률 관측 불가**: 손가락 압력 센서 및 배터리 잔량의 원시 수치는 제공되나, 고수준 완료 및 파지 여부를 기계적으로 판정할 임계치 모델이 부재하여 임의로 추정하지 않고 미지원으로 처리합니다.

---

## 4. 모듈 경계 및 벤더 심볼 검증

남쪽 포트(`G1Link`)는 순수 인터페이스로 선언되어 있으며, 벤더 API 심볼 인용의 정합성은 `vendor-manifest.txt`를 통해 검증됩니다. 실물 기체 연동 검증은 미결(C-3)로 관리됩니다.
