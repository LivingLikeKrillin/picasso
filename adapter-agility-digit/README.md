# adapter-agility-digit — Agility Robotics Digit 어댑터

Agility Robotics Digit 이족 보행 로봇 전용 하드웨어 어댑터 모듈입니다 (ADR 33). 남쪽 통신 포트는 Digit SDK의 WebSocket JSON 프로토콜을 추상화합니다.

---

## 1. 인터페이스 계약 적합성 및 도메인 분석

- 계약 적합성 정본: [`profile/distance/agility-digit.json`](../profile/distance/agility-digit.json)
- 벤더 API 전수 조사: [`profile/vendors/digit.json`](../profile/vendors/digit.json)

**이름 기반 객체 지시 체계**: 4개 기종 중 유일하게 대상을 물리 좌표가 아닌 의미론적 명칭으로 직접 지시할 수 있는 기종입니다. `ObjectSelector{name, april_tag_id, has_attributes, …}` 구조체를 통해 내부 세계 모델에 등록된 객체를 질의하며, `action-pick` 및 `action-place` 액션이 모두 이를 수신합니다. 이는 "사이트 명칭은 기체 내부에 상주한다"는 ADR 35 원칙의 가장 강력한 실증 근거입니다.

과거 비공식 제3자 래퍼 라이브러리를 근거로 조사하여 4개 항목이 오판되었던 이력이 있으며, 1차 공식 자료가 불충분할 경우 `NO`가 아닌 `UNKNOWN`으로 보수적 판정을 내려야 한다는 교훈(§15.65)이 수립되었습니다.

---

## 2. 어댑터 주요 구현 기능

- **실행 트리 기반 진행률 산출**: 액션 실행 트리의 리프 노드 중 완료(`success`)된 노드 수를 집계하여 정량 진행률을 도출합니다. 실행 트리에 런타임 조건 분기가 없어 전체 노드 모수(분모)가 고정되므로 정밀 측정이 가능합니다.
- **액션 갱신 제어 파이프라인**: `remove-action` 후 재전송 시퀀스를 수행합니다. 기존 액션 제거 후에도 상태가 여전히 `running`인 경우 중복 겹침 실행을 방지하기 위해 신규 액션 하달을 대기합니다.
- **실행 트리 기반 파지 추론**: 벤더에서 파지 센서 상태를 직접 발행하지 않으므로 실행 트리의 액션 이력을 분석합니다. 트리에 `action-pick`이 부재할 경우 '빈손'이 아닌 '불가지(UNKNOWN)'로 판정합니다.

---

## 3. 미지원 기능 및 기술적 한계

- **일시정지 미지원**: 벤더 WebSocket 메시지 사양에 일시정지 명령이 부재합니다 (`remove-action`은 완전 취소 명령임).
- **파지 검증 선언 부재 (§15.116)**: 프로파일 상에 `verify_grasp` 지원을 선언하지 않으므로 미들웨어가 해당 선택 파라미터를 하달하지 않습니다.

---

## 4. 모듈 경계 및 벤더 심볼 검증

남쪽 포트(`DigitLink`)는 순수 인터페이스로 선언되어 있으며, 실제 벤더 심볼의 정합성은 `vendor-manifest.txt` 기반의 단위 테스트로 검증됩니다. 실물 기체에 대한 라이브 연동 검증은 미결(C-3)로 관리됩니다.
