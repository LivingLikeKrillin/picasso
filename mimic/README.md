# mimic — 프로파일 구동 가상 로봇 에뮬레이터 (Profile-Driven Robot Emulator)

실물 기체 및 하드웨어 어댑터 쌍을 대체하여 인터페이스 계약(제4계층)을 검증하기 위한 가상 로봇 에뮬레이터입니다. 기종별 구현 클래스를 일체 작성하지 않고, 오직 **선언적 기종 프로파일(JSON)만을 해석하여 거동을 시뮬레이션**합니다 (완료 기준 11 만족).

---

## 1. 아키텍처 핵심 원칙: 완벽한 결정론적 실행 (Deterministic Execution)

- **결정론적 상태 전이 보증 (§12.1)**: 의사 난수 시드(Seed)와 가상 시계(Virtual Clock)를 고정하면 모든 내부 상태 전이 및 이벤트 발생 순서가 100% 동일하게 재현됩니다.
- **비동기 배경 스레드 배제**: 통제 불가능한 시스템 벽시계(Wall Clock)에 의존하는 백그라운드 타이머나 워커 스레드를 일체 두지 않으며, 외부 호출 또는 단일 스텝 틱에 의해서만 시간이 전진합니다.
- `TaskHost`는 `Seeded` 난수 생성기를 엄격히 `private`으로 캡슐화하여, 상위 통신이나 제어 계층에서 비결정론적 난수 추출이 개입할 여지를 원천 차단합니다.

## 2. 모듈 패키지 구조

| 패키지 | 기능 및 역할 |
|---|---|
| `engine/` | 이원화 상태기계: 태스크 수준(`TaskMachine`) 및 스킬 수준(`SkillMachine`). 정량 진행률 산출, 결함 주입 시뮬레이션, 파지 판정, 파라미터 유효성 검사 |
| `transport/` | 인터페이스 계약 gRPC 엔드포인트 구현: 10대 응답 헤더 자동 주입(§5.5), 이벤트 스트림 발행 및 재생 버퍼링, 전송 레벨 장애 주입 |
| `control/` | **별도 분리된 테스트 제어 채널 (Control Channel)**: 의도적 결함 발생, 통신 침묵(Silence), 래치 계약 위반 유도, 시드 주입, 단일 스텝 틱 전진 |
| `profile/` · `RegistrySource.kt` | 프로파일 로컬 파일 로드 및 레지스트리 원격 풀(Pull) 동기화 지원 (자체 주기 폴링 배제, §15.5) |
| `RobotInstance.kt` | 가상 기체 인스턴스 컨텍스트: 세션 식별자, 등록된 사이트 명칭 매핑, 펌웨어 버전 관리 |

## 3. 테스트 전용 제어 채널 분리 설계

테스트 자동화 환경에서는 비정상 결함 강제 주입, 통신 단절 묵비, 완료된 태스크의 허위 진행 유지 등 극한의 오류 주입이 필요합니다. 이러한 시험용 조작 인터페이스가 공개 인터페이스 계약에 포함되면 계약 스펙 자체가 오염되므로, 전용 제어 채널 Protobuf를 별도로 분리하여 운영합니다.

- 제어 채널 Proto는 `buf lint` 및 하위 호환성 검사 대상에서 의도적으로 제외되어 있으며 (§15.32), 필드 번호 예약을 통해 충돌을 방지합니다.
- 인증 체계가 부재하며 (§15.33), 루프백(localhost) 네트워크 바인딩을 통해 시험 환경 내에서만 안전하게 사용되도록 제한합니다.

## 4. 아키텍처 위험 요인 및 방어 전략

- **에뮬레이터의 계약 사칭 위험 (§15.7)**: 표준 계약의 명세가 모호할 때 에뮬레이터가 특정 방식으로 임의 구현하면, 해당 거동이 사실상의 표준으로 오인되어 상이하게 동작하는 실물 기체가 오히려 결함으로 판정될 위험이 있습니다.
- **방어 대책**: 모호한 사양 발견 시 설계 문서를 선행 개정하고, 외부 통합 테스트(`harness/HostParityTest`)를 통해 에뮬레이터와 실물 어댑터 경로가 완전히 동일한 응답을 생성하는지 지속 검증합니다.

---

## 5. 알려진 한계 및 엔지니어링 고려 사항

- **물리적 시뮬레이터와의 구분**: 본 모듈은 물리 엔진 기반의 동역학 시뮬레이터가 아니며 인터페이스 계약 거동만을 재현하는 논리 에뮬레이터입니다 (§12.3).
- **세션 식별자 생성 방식 (§15.21)**: 결정론적 시드 고정과 재기동 시 세션 분리 요구사항의 절충으로 인해 현재는 ULID 대신 프로세스 기동 카운터 기반으로 식별자를 부여합니다.
- **일시정지 중 진행률 누적 한계 (§15.26)**: 일시정지 상태에서도 단순 경과 시간에 기반하여 진행률이 가산되는 한계가 존재합니다.
